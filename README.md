# 📱 QR Code Generator Bot

Простой и удобный Telegram-бот для создания QR-кодов. Отправь текст — получи QR-код мгновенно!

## 🚀 Возможности

- 🔄 **Мгновенная генерация** — любой текст превращается в QR-код за секунду
- 📸 **Отправка как фото** — красивые PNG-картинки прямо в чат
- 📊 **Поддержка любой информации** — ссылки, текст, номера, визитки

## 📸 Пример работы

| Команда | Результат |
|---------|-----------|
| `/start` | Приветствие и инструкция |
| `https://google.com` | QR-код со ссылкой на Google |
| `Привет, мир!` | QR-код с текстом |
| `+79991234567` | QR-код для звонка |

## 🛠️ Технологии

- **Node.js** — серверная часть
- **node-telegram-bot-api** — работа с Telegram API
- **qrcode** — генерация QR-кодов
- **ini** — конфигурация

## 📦 Установка

- 1.Загрузите файлы из репозитория: [Download](https://github.com/aedadai-dev/QRcode-generator-bot/archive/refs/heads/main.zip)
- 2.Создайте bat файл, введите туда команду `npm install`
- 2.Вставьте в `config.ini` токен своего бота
- 3.Запустите `start.cmd`
